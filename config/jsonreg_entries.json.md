## 富集硅岩线

**目标**：从硅岩矿里把富集硅岩（Nq）分离出来。走的是「机械粉碎 → 物理分选 → 湿法冶金 → 高温还原」这套经典稀土/铀系工艺。

| 阶段 | 化学过程 | 目的 |
|---|---|---|
| 一 | 机械粉碎（可选过硫酸钠助磨） | 解离脉石，提高后续浸出率 |
| 二 | 离心物理分选 | 按比重分出**含杂富集硅岩粉**，副产普通硅岩粉 |
| 三 | 硫酸浸出 | Nq 转为可溶硫酸盐，进入液相 |
| 四 | 液相离心 | 分出富集硅岩溶液，废液回流 |
| 五 | 酸化 + 离心析出 | 以 **NqSO₄** 形式固化，副产氟气 |
| 六 | 氢气还原冶炼 | NqSO₄ + H₂ → 热富集硅岩锭 + 硫酸（回收） |
| 七 | 真空冷却 | 得可用富集硅岩锭 |

**闭路循环**：阶段四/五的废液送蒸馏塔回收富集硅岩溶液与硫酸，回阶段三/五；阶段六副产的硫酸同样回流。
**关键副产**：氟气（→ 氢氟酸、蚀刻工艺）、少量金粉与普通硅岩粉。

> ⚠ 本段早期版本照抄 GTCEu 写了一大堆电压/温度/体积参数，与实现差一个数量级，已删除。
> **机器、能耗、体积、产量一律以 scripts/process_naquadah.zs 为准。**

## 超能硅岩线

**目标**：超能硅岩（Nq*）比富集硅岩更重、更放射，需要「重液浮选 → 氟化物体系 → 多级萃取 → 氨水沉淀 → 钙热还原 → 真空升华」才能拿到高纯金属。流程刻意做长 —— 它是 T3 的终局材料，长度本身就是难度。

| 阶段 | 化学过程 | 目的 |
|---|---|---|
| 一 | 惰性气氛（氩）下粉碎 | 防氧化，解离 |
| 二 | 氟碳重液浮选 | 按密度富集，抛出**贫铀废渣** |
| 三 | 氢氟酸浸出 | 转入氟化物/酸溶体系，抛不溶残渣 |
| 四 | 三级离心萃取 | 逐级提纯；分别副产镓/锗、钋/镭、钍、锕系尾液 |
| 五 | 氨水沉淀 | 以氢氧化物形式把超能硅岩从溶液里拿回来 |
| 六 | 低温煅烧脱氨 | 氢氧化物 → 氧化物（**NqO₂**） |
| 七 | 钙热还原 | NqO₂ + Ca → 海绵超能硅岩 + 氧化钙渣 |
| 八 | 真空升华 | 升华提纯得高纯晶体，残渣可回收钨 |
| 九 | 终端加工 | 磨粉后做反应堆燃料 / 与富集硅岩+铱锇合金熔炼 |

**闭路循环**：氟化铵废液蒸馏回收氨与 HF 回阶段三/五；氧化钙渣回钙电解；不溶残渣单独浸出回收稀土与钨。
**放射性与安全**：钋/镭、钍、锕系中间体都是强放射物，设定上要求铅罐储存与干馏固化 —— 这是这条线「长」在叙事上的理由。

> ⚠ 同上：本段早期版本编造了 ZPM 电压、摄氏炉温、爆炸条件等参数，已全部删除。
> **一切数值以 scripts/process_naquadah.zs 为准。**

## 石化

**目标**：原油是多种烃的混合物，靠「脱盐 → 分馏 → 深加工」把它拆成燃料与化工原料。

| 步骤 | 化学过程 | 目的 |
|---|---|---|
| 脱盐 | 水洗脱除盐分与机械杂质 | 防设备腐蚀与催化剂中毒，精炼第一步 |
| 常压蒸馏 | 按沸程分馏 | 分出燃料气、轻石脑油、重柴油、常压渣油 |
| 减压蒸馏 | 减压降低沸点后再分馏 | 从常压渣油里再榨出减压柴油，避免高温裂解 |
| 延迟焦化 | 高温裂解重渣油 | 渣油 → 石油焦 + 焦化气 + 焦化轻油，把最重的部分也变成燃料 |
| 蒸汽裂解 | 石脑油 + 水蒸汽高温断链 | 把长链烃打断成乙烯/丙烯/丁二烯等小分子烯烃 |
| 气体分离 | 低温分馏裂解气 | 把裂解混合气拆成单体烯烃 |
| 芳烃抽提 | 从裂解汽油里抽芳烃 | 得苯 / 甲苯 / 二甲苯 |

**两条分岔**：
- **燃料线**：常压渣油 → 减压 → 焦化 → 加氢脱硫 → 硝基柴油 → 硝基碳燃油（逐级提热值）
- **化工线**：轻石脑油 → 裂解 → 烯烃 → 聚乙烯 / 环氧树脂（塑料与高分子）

**闭路设计**：副产硫酸回流浸出工序、硫化氢回收硫、焦化气与燃料气作为「不浪费」的兜底燃料。

> ⚠ 本段早期版本编造了各馏分的体积分配（如「1000 mB 进料 → 100/200/300/400」）与机器电压，
> 与实现不符 —— 实际常压蒸馏靠 **1 桶流体 + N 个空单元 → (N+1) 桶产物** 实现 ×4 体积放大，
> 每种产物各 1 桶；焦化轻油热值实为 150 而非旧稿写的 55。
> **一切数值以 scripts/oil_chemistry.zs 为准**；燃料热值见下方 §7 汇总表
> （可用 scripts/tools/fuel_ledger.py 复算）。

### 燃料调和与升级

#### 柴油升级
- **加氢脱硫**（化学反应釜）：重柴油 + 氢气 → 超低硫柴油 (130 EU/mB) + 硫化氢  
- **硝基柴油**（化学反应釜）：超低硫柴油 + 硝酸乙酯 → 硝基柴油 (214 EU/mB)  
- **硝基碳燃油**（化学反应釜）：硝基柴油 + 石油焦 → 硝基碳燃油 (244 EU/mB)

> 标定原则：**产物热值 = 上一级原料热值 + 本步能耗 + 余量**（余量 0 ~ 小亏算「不亏」，
> 约 +4k 算「小赚」，两者都合法；只禁止倒亏）。所以高一级燃料的热值必然约等于
> 其原料之和，不能单独拔高某一级，否则漏洞只会转移到相邻步骤。

#### 硝酸乙酯制备（燃料添加剂）
- **空气分离**（离心机）：空气 → 氮气 + 氧气  
- **合成氨**（化学反应釜）：氮气 + 氢气 → 氨 (20 EU/mB)  
- **硝酸生产**（化学反应釜多步）：氨 + 氧气 → 硝酸  
- **乙醇**（化学反应釜）：乙烯 + 水 → 乙醇 (60 EU/mB)，**只有石化乙醇可烧**  
- **硝酸乙酯**（化学反应釜）：乙醇 + 硝酸 → 硝酸乙酯 (74 EU/mB，作为添加剂)

#### 汽油调和
- 轻石脑油 + 苯 → 汽油 (140 EU/mB)

### 塑料及高分子材料

#### 聚乙烯
- **机器**：化学反应釜  
- **输入**：乙烯 + 聚合催化剂（自定义物品，可由矿物加工或任务奖励获取）  
- **输出**：聚乙烯颗粒（物品）  
*聚乙烯是基础塑料，用于合成工业部件、电路基板等。*

#### 环氧树脂（支线）
- **异丙苯**（化学反应釜）：苯 + 丙烯 → 异丙苯  
- **苯酚+丙酮**（化学反应釜，异丙苯氧化分解）：异丙苯 + 氧气 → 苯酚 + 丙酮  
- **环氧氯丙烷**（氯碱 + 丙烯路线，可选深度挑战）：
  - 盐水电解（电解机）：盐溶液 → 氯气 + 氢气 + 氢氧化钠  
  - 丙烯 + 氯气 + 水 → 氯丙醇（化学反应釜）  
  - 氯丙醇 + 氢氧化钠 → 环氧氯丙烷  
- **双酚A**（化学反应釜）：苯酚 + 丙酮 → 双酚A  
- **环氧树脂**（化学反应釜）：双酚A + 环氧氯丙烷 → 环氧树脂（高级材料）
