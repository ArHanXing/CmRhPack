判定公式（与 README 一致）

格子编号 k = floor(x/192)，m = floor(z/192)；
哈希 v = 42·frac(sin(127.1k + 311.7m)·43758.5453) − 21 ∈ [-21,21)；
矿种 = 当前维度切片表中 v 落入的区间（等宽切 N 段）；
球心 = (192k+96, Yc, 192m+96)，半径 R；
中心区块（区块坐标）: Cx mod 12 ∈ {5,6} 且 Cz mod 12 ∈ {5,6}。

注意：星光维度使用自定义区块生成器，DOV 矿脉实际不生效（表中仅列出配置）。
哈希值恰好落在切片边界的格子（概率~0）可能因 JS/Java 浮点实现差异与游戏内结果不同。
