判定公式与说明

格子编号 k = floor(x/192)，m = floor(z/192)；
哈希 v = 42·frac(sin(127.1k + 311.7m)·43758.5453) − 21 ∈ [-21,21)；
矿种 = 满足 lo ≤ v ≤ hi 的那条矿脉（阈值取自矿脉 JSON 的 density_threshold 门）；
若某格不落在任何区间 → 该格为空矿格；
球心 = (192k+96, Yc, 192m+96)，半径 R；
中心区块（区块坐标）: Cx mod 12 ∈ {5,6} 且 Cz mod 12 ∈ {5,6}。

星光维度使用自定义区块生成器，DOV 矿脉实际不生效（仅列出配置）。
哈希恰好落在切片边界（概率~0）时，JS/Java 浮点差异可能给出不同结果。
数据由 tools/sync_vein_map.py 从矿脉 JSON 生成；改完矿脉后重跑该脚本即可同步。
