## 1. 新合金：强化硅岩合金（在既有硅岩合金上加改）

### 1.1 为什么不另起一套

现有 `naquadah_alloy` = **Nq₂W₇Ni**（钨重合金型：W 基体 + Ni 粘结相 + 硅岩强化相），
已经有一套完整管线（大化反 → 电高炉 → 真空冷冻 → 板/杆），
并且已经绑定了专用出口（`coil_naquadah` 硅岩线圈）。

新合金的组分与它高度相似 —— 都是「硅岩 + 难熔金属 + 少量合金元素」——
所以**不建平行合金**，而是在它基础上做一道**强化改性**：
以既有粉为基体，加钛 + 铬 + 碳化硅，升级为结构材料。

这样得到四个好处：

1. 新增物品从 6 个降到 **5 个**；
2. 复用既有全部机器与热值阶梯，不引入新工艺概念；
3. 两条合金形成清晰递进：`硅岩合金`（功能件，做线圈）→ `强化硅岩合金`（结构件，做外壳）；
4. **Nq⁺ 的要求已由基体满足** —— 既有配方用的就是 `enriched_naquadah_dust`，
   强化步不必再重复添加，避免同一元素在两处重复计价。

### 1.2 成分与依据

| 组分 | 摩尔 | 作用 | 依据 |
|---|---|---|---|
| **Nq⁺₂W₇Ni**（既有） | 10 份 | 基体 | 既有钨重合金型合金，**基体已用富集硅岩**（`enriched_naquadah_dust`）。W 本身是强 α 稳定剂 + 固溶强化相，故不再额外补 Al |
| **Ti** | 4 | 比强度担当 | Ti-6Al-4V：抗拉 ~950 MPa，密度 4.43 g/cm³，比强度 ≈215 kN·m/kg |
| **Cr** | 3 | β 相稳定剂 + 抗氧化 | 真实存在 Ti-5Al-2.5Cr；本包无 V，用 Cr 顶替 |
| **SiC** | 3 | 颗粒增强，做成金属基复合材料（MMC） | SiC/Ti-6Al-4V 是真实航天材料，比基体强度高 10–20%，耐磨大增 |

> **注**：基体已经是 Nq⁺₂W₇Ni（既有配方用的就是 `enriched_naquadah_dust`），
> 所以强化步**不再重复添加富集硅岩** —— Nq⁺ 的要求由基体本身满足。

太空电梯结构件的瓶颈是**比强度**（强度/密度）和**抗蠕变**，不是硬度 ——
所以选 Ti 基 + 颗粒增强，而不是继续堆钨重合金。

### 1.3 工艺链

```
① 基体批次（既有配方，一字不改）
   钨粉 ×7 + 硅岩粉 ×2 + 镍粉 ×1   →  硅岩合金粉 ×10
   电高炉 heat 4500（加催化剂 3500）→ 热锭 → 真空冷冻 → 硅岩合金锭

② 强化批次（新增，大化反，5 进 / 4 出）
   硅岩合金粉 ×10 + 钛粉 ×4 + 铬粉 ×3 + 碳化硅粉 ×3
        →  强化硅岩合金粉 ×20
   质量守恒 10+4+3+3 = 20 ✅    输入 4 个 ≤ 大化反 6 槽 ✅

③ 热强化锭（电高炉）
   强化粉 ×1  →  热强化锭 ×1          heat 5000（加催化剂 4000）

④ 冷锭（真空冷冻机）   热强化锭 ×1  →  强化锭 ×1
⑤ 板 / 杆             强化锭 ×1 →(压缩机) 强化板 ×1
                      强化锭 ×1 →(车床)   强化杆 ×1
⑥ 机械外壳（精密装配） 强化板 ×4 + 昶铂框架 ×1  →  space_elevator_casing ×1
```

**批次账很干净**：1 批基体（10 粉）→ 正好喂满 1 批强化（需 10 粉）；
强化批出 20 粉 = 20 板，每外壳吃 4 板 → **两批大化反正好做 5 个机械外壳**。

### 1.4 热值阶梯（与既有合金衔接）

| 合金 | 裸烧 | +灵魂注入催化剂 | 可达线圈 |
|---|---|---|---|
| 硅岩合金（既有） | 4500 | 3500 | RTM 合金 4000 / 硅岩 5000 |
| **强化硅岩合金** | **5000** | **4000** | 硅岩 5000 / RTM+催化剂 4000 |

5000 正好等于当前可选**最高线圈热值**，所以量产外壳必须先做出硅岩线圈 ——
与既有合金形成干净递进，且不突破 5000，避免产生无线圈可达的死配方。

## 2. 超高强度混凝土（UHPC）

### 2.1 真实依据

普通混凝土抗压 **20–40 MPa**；UHPC（Ductal 类）可达 **150–200 MPa**。
差距不来自骨料，而来自三条：

1. **极低水胶比**（0.18–0.22，普通混凝土约 0.5）；
2. **硅灰 + 石英粉级配填充** —— 把纳米级孔隙填掉；
3. **钢纤维增韧**（2–3% 体积掺量）—— 把脆性破坏变成延性。

### 2.2 ⚠ 废料依赖问题（本设计的重点）

你提的这点是对的：`calcium_oxide_slag`（氧化钙渣）和 `calcium_sulfate_dust`（石膏粉）
在包里**都只是别的产线的副产**，产量不稳定、不可控。若 UHPC 成为它们的
重要消费者，整条太空电梯线就会被上游某个无关产线的开工率卡死。

**解决办法：为钙源和石膏各建一条基于可开采原料的独立批量路线。**

| 中间品 | 独立路线 | 依据 |
|---|---|---|
| 生石灰 CaO | **方解石粉 → 煅烧 → 生石灰** | 方解石 `minecraft:calcite` 是晶洞常见矿，**可开采 = 稳定**；真实石灰就是石灰石煅烧 |
| 石膏 CaSO₄ | **生石灰 + 硫酸 → 石膏** | CaO + H₂SO₄ → CaSO₄ + H₂O；硫酸由既有 `oritech:still_sulfuric_acid` 供应 |

这样 UHPC 线**完全不依赖任何副产**。既有的两个副产可以照旧存在
（作为免费补充，而不是唯一来源）。

> 方解石供给已确认：`techreborn:calcite_dust` 可由 `grinder_parity.zs` 的
> pulverizer 配方稳定产出，原矿 `minecraft:calcite` 无限可采。

### 2.3 工艺链

```
A1 生石灰（电高炉，煅烧）
   方解石粉 ×2  →  生石灰 ×1                        heat 1000
   依据：CaCO₃ → CaO + CO₂（摩尔 1:1，质量 100→56，取 2:1 保守）

A2 石膏（化反，2 进 / 2 出）
   生石灰 ×1 + 硫酸单元 ×1  →  石膏粉 ×1 + 空单元
   依据：CaO + H₂SO₄ → CaSO₄ + H₂O
   （复用既有 jsonreg:calcium_sulfate_dust，但来源变成可量产）

A3 水泥熟料（电高炉，高温烧结）
   生石灰 ×3 + 石英粉 ×1 + 铝粉 ×1  →  水泥熟料 ×5    heat 1500
   依据：真实熟料 CaO 65% / SiO₂ 21% / Al₂O₃ 6%，
         矿物相 C₃S(阿利特) + C₂S(贝利特) + C₃A

A4 水泥（磨粉机，掺石膏调凝）
   水泥熟料 ×19 + 石膏粉 ×1  →  水泥 ×20
   依据：真实水泥掺石膏约 5%，用于调节凝结时间

B   UHPC 拌合料（大化反）
   水泥 ×10 + 石英粉 ×2 + 钢纤维 ×1 + 水单元 ×1
        →  UHPC 拌合料 ×13 + 空单元 ×1
   质量守恒 10+2+1 = 13 ✅
   依据：低水胶比 —— 1 单元水对 13 份胶凝料，远低于普通混凝土的约 0.5
```

### 2.4 钢纤维

真实钢纤维是冷拔钢丝切断而成。包内没有 `techreborn:steel_rod`，但有
`techreborn:steel_plate`。建议：

```
钢板 ×1  →(车床)  钢纤维 ×4        time 40, power 8
```

> 加载顺序注记：`lathe.zs`(l) 先于 `space_elevator.zs`(s) 加载，
> 其 `lathe.removeAll()` 不会清掉这里追加的配方。

### 2.5 可选细化：蒸汽养护

真实 UHPC 必须**蒸汽养护（约 90°C）**才能到最终强度，否则只到 60% 左右。
要体现的话可加一步 `UHPC 拌合料 →(蒸汽养护) → 养护后 UHPC`，
代价是多一个中间品和机器约束。

**我倾向先不加**，保持链路清爽；但这是让 UHPC 真正区别于普通混凝土的最真实一步，
你要的话可以补。

## 3. 方块配方

### 3.1 两个混凝土方块

用**钢纤维掺量**区分，对应真实的承压件 vs 非承压件：

```
承压支撑混凝土 ×4（精密装配）   time 400, power 128
   UHPC 拌合料 ×4 + 钢纤维 ×1 + 钨钢板 ×1
   → 高纤维掺量 = 高抗压，用于承载结构

内部结构混凝土 ×4（精密装配）   time 400, power 128
   UHPC 拌合料 ×4 + 铝板 ×1
   → 低纤维、轻量，用于内部填充
```

### 3.2 机械外壳

沿用 `multiblock_casing.zs` 里 6 种外壳的统一形制（精密装配，时间 100–400，功率 128）：

```
space_elevator_casing ×1（精密装配）   time 400, power 256
   强化硅岩合金板 ×4 + 昶铂框架 ×1
```

### 3.3 单块成本核算

**机械外壳**（每 5 个外壳消耗）：
```
20 强化粉  ← 硅岩合金粉 10 + 钛粉 4 + 铬粉 3 + 碳化硅粉 3
20 强化板  ← 20 强化粉
 5 外壳    ← 20 强化板（每外壳 4 板）

其中 硅岩合金粉 10 ← 钨粉 7 + 富集硅岩粉 2 + 镍粉 1
```

| 资源 | 每 5 外壳 | 每 1 外壳 |
|---|---|---|
| 钨粉 | 7 | 1.4 |
| 富集硅岩粉 | 2 | 0.4 |
| 镍粉 | 1 | 0.2 |
| 钛粉 | 4 | 0.8 |
| 铬粉 | 3 | 0.6 |
| 碳化硅粉 | 3 | 0.6 |
| 昶铂框架 | 5 | 1 |

**混凝土**（1 块承压支撑）：
```
UHPC    1      ← 水泥 10/13 = 0.769
水泥    0.769  ← 熟料 0.731 + 石膏 0.038
熟料    0.731  ← 生石灰 0.439 + 石英粉 0.146 + 铝粉 0.146
生石灰  0.439  ← 方解石粉 0.877
钢纤维  0.25   ← 钢板 0.0625
```

| 资源 | 每 1 块承压支撑 | 每 1 块内部结构 |
|---|---|---|
| 方解石粉 | 0.88 | 0.88 |
| 石英粉 | 0.15 | 0.15 |
| 铝粉 | 0.15 | 0.15 |
| 钢纤维 | 0.25 | — |
| 钨钢板 | 0.25 | — |
| 铝板 | — | 0.25 |

量级是合适的：混凝土是**大宗建材**（搭大型结构要铺很多块，单块必须便宜），
机械外壳是**精密件**（成本高、用量少）。

   两条都是有限产线，需确认在 T2 末期能否支撑「造电梯」这种量级的消耗。
   **如果偏紧，最省事的调节阀是外壳产出的板数（4 → 6），而不是改成分。**

4. **是否启用蒸汽养护**（见 2.5）。

5. **`structure_concrete` 的定位**：已注册、有贴图、无配方，看起来像是本次
   两个混凝土块的「通用前置」。要不要给它一条普通混凝土配方（UHPC 的低配版）？
   本次默认不动。

6. **脚本落点**：建议新建 `scripts/space_elevator.zs`（'s' 前缀，
   落在 `refinedstorage.zs`(r) 之后、`t1.zs`(t) 之前）。
   已确认其后没有任何脚本对 `blast_furnace` / `vacuum_freezer` /
   `compressor` / `lathe` / `precise_assembler` / `large_chemical_reactor`
   调用 `removeAll()`，加载顺序安全。

## 6. 与既有体系的一致性检查

| 检查项 | 结果 |
|---|---|
| 热值是否超出可达线圈 | ✅ 最高 5000，正好 = 硅岩线圈 |
| 是否依赖不稳定副产 | ✅ 已用方解石 / 硫酸独立路线解耦 |
| 质量是否守恒 | ✅ 基体 7+2+1=10、强化 10+4+3+3=20、UHPC 10+2+1=13 |
| 是否与既有合金重复 | ✅ 不建平行合金，直接以 `naquadah_alloy` 为基体 |
| 是否复用既有中间品 | ✅ `silicon_carbide_dust` / `quartz_dust` / `calcium_sulfate_dust` / 昶铂框架 / 钢板 / 铝板 |
| 是否抢占 T3 材料 | ✅ 无（不用超能硅岩、虚素、三重钛等） |
| 机器槽位是否超限 | ✅ 大化反 4 进（限 6）/ 4 出（限 4）、电高炉 1 进、精密装配 2 进 |
