# 太空挖矿系统设计（CmRhPack）

## 1. 设计定位

太空挖矿要同时干三件事：

1. **后期矿石大头来源** —— Avaritia 奇点。单个奇点 `cost: 400` 个存储块
   （= 3600 锭），10 种奇点，地面产线撑不住这个量级。
2. **补缺口** —— `raw_naquadria` 目前无产出，归位到深空。
3. **可扩展** —— 加一颗星应该是「1 个卫星物品 + 1 条配方」，不是改架构。

**不是**「换个地方挖同样的铁」。地面 T1–T2.3 已经把常见矿自动化了，
太空的价值在**量级**和**地面拿不到的东西**。


### 2.3 MK 分级 = 射程，不是速度


| MK-I | RP-1/液氧 **或** 甲烷/液氧 | 近地轨道 |
| MK-II |  硝酸肼/N₂O₄ **或** 偏二甲肼/N₂O₄ | 内行星带 |
| MK-III | 液氢/液氧 | 1200 | 深空 |

mk3的造价将会贼几把贵，以此来匹配液氢液氧的超低造价

### 4.2 无人机灌注（化反 `chemical_reactor`）

```
无人机 MK-I + RP-1 燃料罐  →  已灌注无人机 MK-I + 空罐
无人机 MK-II + 甲烷/MMH/UDMH 燃料罐 → 已灌注无人机 MK-II + 空罐   （3 条）
无人机 MK-III + 液氢燃料罐 → 已灌注无人机 MK-III + 空罐
```

罐子守恒：1 进 1 出。

### 4.3 采矿（采矿模块 `space_elevator_miner`）

```
卫星（返还）+ 已灌注无人机 MK-N → 卫星 + 矿石 ×3
```

| 配方 | time | power | EU/次 |
|---|---|---|---|
| LEO | 200 | 1024 | 204,800 |

无人机消耗、卫星返还 —— 所以**每次运行的真实成本 = 1 架无人机 + 1 罐燃料**。

## 5. 平衡核算

### 5.1 单位成本

| 天体 | 产出总数/次 | EU/次 | **EU / 件** |
|---|---|---|---|
| LEO | 96 | 204,800 | **2,133** |
| 内行星 | 64 | 1,638,400 | **25,600** |
| 深空 | 28 | 13,107,200 | **468,114** |

深空贵是应该的（超能硅岩本来就在 T3），但 468k EU/件需要和
`process_naquadah.zs` 现有超能线对比后再定，**待核**。

### 5.2 奇点量产速度（LEO）

1 个铁奇点 = 400 块 = 3600 锭 ≈ 3600 粗铁。
LEO 每 200t 出 48 粗铁 → **15,000 t ≈ 12.5 分钟**（单模块满速）。

考虑到 Avaritia 需要 10 种奇点且每种可能要多份，这个速度偏慢但可接受，
玩家会并多个采矿模块。**这是设计意图**：太空挖矿是「铺规模」而不是「造一台」。

### 5.3 与地面产线的关系

太空**不替代**地面，是地面之上的量级放大。地面产线仍然负责：
- 所有中间品加工（太空只出粗矿）
- 绿宝石/石英/紫水晶
- 硅岩线的精细部分

## 6. 扩展性设计

加第 4 颗星的成本：

1. `jsonreg_entries.json` 加 1 个卫星物品（+ 贴图）
2. 组装机加 1 条卫星配方
3. 采矿机加 1 条采矿配方
4. 若需要新燃料，复用 `rocket_fuel.zs` 既有推进剂

**不需要改架构、不需要新机器、不需要写 Java。**

如果将来需要「同一颗星挖不同矿」，再加**钻头（drill head）** 作为
配方选择器：`卫星 + 无人机 + 钻头 → 卫星 + 特定矿石`，钻头消耗。
这是二期扩展点，一期不做，保持链路清爽。
