# 乙烯发电产区（懒人版线路）设计

> 状态：**设计稿**，等你确认后再写脚本。
> 目标：给「懒人玩家」一条**机器少、不用盯、不依赖石油**的发电路线。

---

## 0. 先给结论

**乙烯是可以自持发电的，但只有一条路能自持，且发电量不高。**

| 路线 | 净发电 | 能否自持 | 机器数 | 需要盯吗 |
|---|---|---|---|---|
| A. 生物质 → 生物乙醇 → 乙烯 → 烧 | **+63.9 EU/t** | ✅ 能（要种树） | 5 台 | ❌ 不用 |
| B. 石油分馏副产乙烯 → 烧 | 视石油产能 | ✅ 能 | 3 台 + 蒸馏塔 | ❌ 不用 |
| C. 乙烯再加工成塑料 | — | ❌ 净消耗 | 更多 | — |

路线 A 的净产出是 **63.9 EU/t**，只能带动 1~2 台机器。这不是主力电源，而是**「挂机备用电源」**——正好符合「懒人」定位：种下去就不用管了。

## 1. 关键数据（全部来自脚本与 dump，非估算）

### 1.1 乙烯链能耗

| 步骤 | 机器 | time | power | 能耗 |
|---|---|---|---|---|
| 生物质 → 发酵液 | Lychee 发酵池（水中） | **240 秒** | 0 | 0 |
| 发酵液 → 生物乙醇 | OR 流体离心 | 200 | 64 | 12,800 |
| 生物乙醇 → 乙烯 | TR 化反 | 200 | 30 | 6,000 |
| 乙烯燃烧 | TR 燃气发电机 | — | 77 | — |

*（发酵池无耗电，但**240 秒 + 必须在水里 + 掉落物形态**是这条线唯一的门槛）*

### 1.2 产出核算（1 批 = 1 桶乙烯）

```
1 桶乙烯 → 燃气发电机 77 EU/t × 1000 tick = 77,000 EU
上两步能耗 = 12,800 + 6,000 = 18,800 EU
────────────────────────────────────────────
净产出 = 58,200 EU/桶 = 58.2 EU/t
```

若改用**大型燃气轮机**（1024 EU/t，复用 gas_generator 配方）：
```
净产出 = 77,000 − 18,800 = 58,200 EU/桶（不变，机器只影响速度）
```

**结论：乙烯净热值 ≈ 58 EU/t/桶，是同量柴油（189k）的 41%。** 低，但白送。

### 1.3 生物质的来源（决定能否自持）

| 来源 | 输入 | 产出 | 评价 |
|---|---|---|---|
| `pulverizer/hay_block` | **1 干草块** | **16 生物质** | ✅ 最优，种小麦即可 |
| `pulverizer/biobasic` | `c:biomatter` 标签 | 1 | 需树场/作物 |
| `pulverizer/recycle/biomass` | 回收 | 1 | 拾荒 |

**干草块路线是 16 倍产出**，一株小麦=1 小麦=9 个才 1 干草块，但 1 干草块 = 16 生物质 = 4 批发酵液（每批 4 生物质）。所以：

```
1 干草块 → 16 生物质 → 4 批发酵 → 4 桶生物乙醇 → 4 桶乙烯
→ 4 × 77,000 = 308,000 EU
```

**一个 9×9 小麦农场足够带 60~100 EU/t 的稳定输出。**

## 2. 推荐产区布局（懒人版，5 台机器）

```
                 ┌─────────────┐
   小麦农场  ───→ │ 粉碎机(OR)  │ 干草块 → 16 生物质
   (9×9 自动)     └──────┬──────┘
                         │ 生物质
                    ┌────▼─────┐
                    │ 发酵池    │ 需水方块 + 240s（Lychee，掉落物形态）
                    │ (水中)    │ ⚠ 可并联多个
                    └────┬─────┘
                         │ 发酵液单元
                    ┌────▼──────┐
                    │ OR 流体离心│ 发酵液 → 生物乙醇
                    └────┬──────┘
                         │ 生物乙醇单元
                    ┌────▼─────┐
                    │ TR 化反   │ 生物乙醇 → 乙烯
                    └────┬─────┘
                         │ 乙烯
                    ┌────▼──────────┐
                    │ TR 燃气发电机  │ 77 EU/t
                    │ ×N            │ N 按需
                    └───────────────┘
```

**机器清单（全 T1 可得）：**

| # | 机器 | 数量 | 作用 |
|---|---|---|---|
| 1 | Oritech 粉碎机 | 1 | 干草块 → 生物质 |
| 2 | Lychee 发酵池（水中） | 2~4 | 生物质 → 发酵液，**唯一需要并联的一环** |
| 3 | OR 流体离心机 | 1 | 发酵液 → 生物乙醇 |
| 4 | TR 化反 | 1 | 生物乙醇 → 乙烯 |
| 5 | TR 燃气发电机 | 2~4 | 烧乙烯 |

## 3. ⚠ 三个必须知道的问题

### 3.1 发酵池是整条线的瓶颈

```
发酵 240 秒 / 批，其余三步都是 200 tick = 10 秒
```

**发酵占总时长的 96%。** 想提高产量只能并联发酵池——但每池要占一块水、且是 Lychee 掉落物形态，不能管道化。这是「懒人」方案的最大妥协：**要么接受低产，要么手动摆很多池子。**

### 3.2 生物乙醇不可燃烧

我查过：`jsonreg:bio_ethanol` **没有任何燃烧配方**。所以它只能转乙烯，不能直接烧。这反而是好事——逼你走完整条链，避免中途截流。

### 3.3 这条线**不能**当主力电源

净 58 EU/t/桶，而 T2 电网需求是 2000 EU/t。按 1 桶 = 1000 tick 算：

```
2000 EU/t 需要乙烯 2000/58 ≈ 34 桶/分钟
= 34 次发酵/分钟 = 需 136 个并联发酵池
```

**不可能。** 所以这条线的定位必须明确：

> **它是「挂机备用电源 / 早期补贴」，不是主力。** 主力仍是石油柴油线。

## 4. 三个可选强化方向

如果你想让它更有用，我建议选一个：

### 方案 A：给发酵池开一条「机器化」路线（推荐）

现在生物质 → 发酵液必须泡水 240 秒。可以加一条 **TR 化反** 的等价配方：

```
生物质 ×4 + 水单元 ×1 →(TR 化反, 200 tick, power 30) 发酵液单元 ×1
```

**效果**：发酵从 240 秒降到 10 秒，整条线彻底自动化，产量提升 24 倍。
**代价**：削弱了原本的 Lychee 玩法（但那条本来就对懒人不友好）。

### 方案 B：提高乙烯燃烧值

现在 77 EU/t（= 77,000/桶），是柴油的 41%。若提到 **120**，净产出变成 101 EU/t，翻 1.7 倍。
**代价**：乙烯同时是塑料原料，提高燃烧值会让玩家更倾向烧掉而不是做塑料。

### 方案 C：不改，作为「备份电源」存在

保持现状，定位为「石油线断了也不至于全厂停摆」的保险。零改动。

---

## 5. 我的建议

**选 A**。理由：

1. 你的诉求是「懒人」「线路短」，而 240 秒发酵 + 掉落物形态是对懒人最不友好的设计；
2. 方案 A 只加**一条配方**，不改任何既有数值，风险最低；
3. 加完之后这条线从「摆设」变成「真正可用的小型电源」，净 58 EU/t × 并联数，配合大燃气轮机可以撑起一个独立车间。

需要你确认：
- 走 A 的话，发酵池的 Lychee 原配方**保留**（不删），只是多一条化反捷径？还是直接替换掉？
- 乙烯燃烧值要不要一起提到 120（方案 B）？

## 附：本次已执行的改动

**常压渣油加入柴油发电机**（`scripts/oil_chemistry.zs`）：

```zs
<recipetype:techreborn:diesel_generator>.addJsonRecipe(
  "oil.burn.trdiesel/atmospheric_residue",
  {type: "techreborn:diesel_generator", power: 67, fluid: "jsonreg:atmospheric_residue"});
```

power 67 取 `fuel_ledger` 的市场口径（67,000 EU/桶），与其它燃料一致。

**额外收益（字节码确认）**：大型内燃机 `LargeCombustionEngineBlockEntity` 复用
`ModRecipes.DIESEL_GENERATOR`，大型燃气轮机复用 `ModRecipes.GAS_GENERATOR` ——
所以渣油现在**自动可进大型内燃机（1024 EU/t）**，不必另写配方。
