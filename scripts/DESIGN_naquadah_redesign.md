# 硅岩处理线重写设计方案

来自 Opus 5.5。有点傻傻的，可能是反代导致的。
## 设计目标
- 新机器必须在**末地环境**运行，需要钨钢线圈解锁
- 包含**动态平衡机制**（温度/压力/辐射需实时监控与调节）
- 是富集硅岩线的**核心瓶颈**，玩家必须先制造它才能继续
- 挑战在于**自动化设计**而非手动操作

---

## 核心新机器：**末地共振稳定器**（Ender Resonance Stabilizer）

### 机器定位
- **解锁时机**：T2.4，在获得钨后、处理富集硅岩前
- **必需组件**：钨钢线圈（提供高磁场强度）+ 钨钢机械外壳
- **放置要求**：必须在**末地维度**且 Y < 60 否则直接不工作
- **功能**：将 `含杂富集硅岩粉` 稳定化处理为 `稳定富集硅岩粉`，这是所有后续富集硅岩工艺的**唯一前置**

对于源码实现 Agent 你不需要管结构如何、合成表如何，设计机制即可。
### 工作原理（动态平衡机制）

机器有 **4 个实时监控参数**。以下都是值域 [0,15]

#### 1. **共振强度（Resonance）** 
- 由末地环境自然产生，基础值 = 5
- **过低**（<=3）：工作，但是产生废料
- **过高**（>=10）：共振崩溃，产生爆炸
- 每5tick随机跳变±1
**调节方法**：
- **提升**：注入 `末影珍珠粉` 
- **降低**：注入 `虚空水晶碎片`（transmog）

#### 2. **热力负荷（Thermal Load）** 
- 反应过程产热，基础增速 +1/3tick
- **过低**（<=3）：不工作
- **过高**（>=10）：工作时候每tick都有10%可能性突然停机重启反应过程

**调节方法**：
- **降温**：注入 `冰`
- **加热**：注入 `岩浆`

#### 3. **虚空辐射（Void Radiation）**
- 末地天然辐射 + 硅岩本身放射性，基础增速 +1/tick
- **过高**（>=12）：污染产物，产出 `辐射污染硅岩废料`

**调节方法**：
- **吸收**：注入 `铅粉`（techreborn）或 `贫铀废渣`

#### 4. **压力稳定度（Pressure Stability）**
- 初始 10，每次反应 -1，机器空转时 +1/20tick 恢复
- **过低**（<=2）：机器需要冷却，强制进入 200 tick 冷却期(Jade显示)
**调节方法**：
- 只能通过**暂停反应**让其自然恢复
- 玩家需要设计"轮转系统"：多台稳定器交替工作

上面所有的具体物品配置都用到了整合包内的注册物品，我们不需要注册它们，所以我们需要在 TR 的 config 下新开一个单独存放这些定义的json文件

### 整合包内配方设计

#### 主配方（核心转化）
```
输入：
  - 含杂富集硅岩粉 ×1
  - 调节用物品
  - 功率：512 EU/t
  - 时间：400 tick（20秒）

输出（取决于参数）：
  - 理想状态（4参数全在理想区间）：
    → 稳定富集硅岩粉 ×1 + 空单元 ×1
  - 次优状态（3个参数达标）：
    → 稳定富集硅岩粉 ×1 + 辐射废水 ×100mB
  - 失败状态（<3个参数）：
    → 辐射污染硅岩废料 ×1
  - 灾难状态：
    → 爆炸
```

#### 辅助配方（废料回收）
```
辐射污染硅岩废料 + 10B 硫酸 + 5 铅粉 
  → 离心机（600 tick）
  → 含杂富集硅岩粉 ×1 + 放射性废液 200mB
```

## 实现方式

### 核心机制

#### 红石信号输出（脉冲编码）
- **输出面**：机器底面（bottom）输出脉冲序列
- **编码周期**：每 220 tick（11秒）一轮
  - tick 0-19：输出共振强度（1-15）
  - tick 40-59：输出虚空辐射（1-15）
  - tick 80-99：输出热力负荷（1-15）
  - tick 120-139：输出压力稳定（1-15）
  - tick 160-219 和前面的所有未标注的：间隔期（信号=0）

- **参数失衡响应**：
  - 任一参数离开理想区间 → 标记为"失衡状态"
  - 失衡状态持续 **160 tick（8秒）** 仍未修正 → 触发事故

#### 红石信号输入（紧急停机）
- **输入面**：机器顶面（top）
- 检测到红石信号（>0）→ 立即停止反应，参数冻结，8秒内恢复不触发事故
- 用途：玩家发现参数异常时手动暂停，或自动化系统检测到灾难前兆时紧急制动

#### GUI/Jade 显示
- 4 个参数条，实时数值 + 颜色编码：
  - 绿色：理想区间
  - 红色：危险，8秒内必须修正
- 失衡倒计时：显示"事故倒计时：123 tick"
- 压力值单独显示："压力：5/15 | 剩余运行次数：3"
- 使用 Jade 加上另外三个平衡值的显示
- 6输入4输出（蒸馏塔模板？），此外 **前2个输入放配方输入物品，后4个输入放调节用物品**
